# Aster — Academic Intelligence

Aster is a student academic analytics application built with Python, Streamlit, machine learning, and interactive visualizations.

It helps explore academic performance, understand relationships between study habits and results, and review individual student report cards.

## Features

### 1. Academic Performance Analysis
Explore student performance using study hours, attendance, previous scores, assignment completion, and sleep hours.

### 2. Machine Learning
Uses a Random Forest regression model to estimate final student scores from academic and study-related features.

### 3. PDF Report Card Analysis
Upload an individual student's academic report card in PDF format, review extracted text and detected marks, and generate a subject-wise performance summary.

### 4. Interactive Visualizations
Explore charts and model evaluation results using interactive graphs with zoom, pan, and hover controls.

### 5. Dataset Explorer
Explore the demonstration dataset and inspect student performance information.

## Technology Stack

- Python
- Streamlit
- pandas
- NumPy
- scikit-learn
- Plotly
- PDF text extraction
